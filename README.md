# Multi Business

**Multi Business** একটি সহজ ও ব্যবহারবান্ধব ওয়েব অ্যাপ্লিকেশন। এটি Android ফোন এবং Windows কম্পিউটারের ব্রাউজারে ব্যবহার করা যায়।

## 🚀 Live App

অ্যাপটি GitHub Pages-এ প্রকাশ করার পর এখানে লিংক যুক্ত করো:

`https://YOUR-USERNAME.github.io/multi-business/`

## 🌐 GitHub Pages দিয়ে Live করার নিয়ম

১. GitHub-এ একটি নতুন Repository তৈরি করো।

২. Repository-এর নাম দাও `multi-business`।

৩. `index.html` এবং `README.md` ফাইল দুটি Repository-তে Upload করো।

৪. Repository-এর **Settings** থেকে **Pages** অপশনে যাও।

৫. Build and deployment অংশে নিচের সেটিংস করো:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/(root)`

৬. Save বাটনে ক্লিক করো।

কিছুক্ষণ পর তোমার ওয়েব অ্যাপ Live হয়ে যাবে।

## 📲 Android-এ Install করার নিয়ম

১. Android ফোনে Google Chrome খুলে Live App-এর লিংকে প্রবেশ করো।

২. Chrome-এর তিন ডট মেনুতে ক্লিক করো।

৩. `Add to Home screen` নির্বাচন করো।

৪. অ্যাপের নাম হিসেবে `Multi Business` দাও।

৫. Add চাপো।

এখন Home Screen থেকে অ্যাপটি চালাতে পারবে।

## 💻 Windows-এ Install করার নিয়ম

১. Windows PC-তে Google Chrome খুলে Live App-এর লিংকে প্রবেশ করো।

২. Chrome-এর তিন ডট মেনুতে যাও।

৩. `Cast, save and share` থেকে `Install page as app` অপশনটি থাকলে সেটি নির্বাচন করো।

৪. Install করে Start Menu থেকে অ্যাপটি চালাও।

## 💾 Data Backup এবং সতর্কতা

- অ্যাপের ডেটা Browser-এর Local Storage-এ সংরক্ষিত হয়।
- Android ও Windows-এর ডেটা আলাদাভাবে সংরক্ষিত থাকে।
- শুধু GitHub Pages-এ Live করলে দুই ডিভাইসের ডেটা স্বয়ংক্রিয়ভাবে Sync হবে না।
- Browser-এর Site Data মুছে ফেললে সংরক্ষিত ডেটা হারাতে পারে।
- নিয়মিত Backup নিয়ে নিরাপদ স্থানে সংরক্ষণ করো।
- অন্য ডিভাইসে ডেটা ব্যবহার করতে Backup ও Restore সুবিধা ব্যবহার করতে পারো।

## ☁️ Google Drive Sync

Google Drive Sync ব্যবহার করতে হলে Google Apps Script Web App URL সেটআপ করতে হবে। শুধু GitHub Pages-এ Upload করলেই Google Drive Sync চালু হবে না।
